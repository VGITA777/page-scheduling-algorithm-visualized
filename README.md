# Page Scheduling Algorithm Visualizer

### FEATURES

- Real Time Solving
- FIFO Algorithm
- LRU Algorithm

---

### HOW TO USE

- Use java 21 or higher.
- Run the program by executing the Main or App class.
- Alternatively, you can run the jar file from the releases.

---

### DESCRIPTION

- A simple project to visualize page scheduling algorithms in real time or manually.
- Given as a final project requirement for the Operating Systems course.
